# 플레이테스트 카드 시트 — 페르소나 5종

> 목적: 페이퍼 프로토 또는 초기 디지털 빌드용 풀 데이터 시트.
> 디자이너가 일러스트 의뢰, 개발자가 그대로 구현 가능한 수준의 명세.

선택 5종은 페르소나 풀의 **다양성을 대표**하도록 큐레이션:
1. **NULL-07** — 튜토리얼/스토리 핵심 (U)
2. **KAYA-22** — 가장 평범한 페르소나 (C)
3. **MEI-19** — 트레잇 기반 시각적 임팩트 (U)
4. **NIRVANA** — 비인간성 회복 메커닉 (L)
5. **REAPER-13** — 시장 조작 메커닉 (L)

## 카드 #1 — NULL-07

```

│ ID: NULL-07                       [U]    │
│ ─────────────────────────────────        │
│ HAIR:    Black short bob                 │
│ OUTFIT:  Grey hoodie                     │
│ ACC:     None                            │
│ BG:      Void (pure black)               │
│ AURA:    Glitch                          │
│ ─────────────────────────────────        │
│ EGO:        65 / 100                     │
│ START PRICE: 0.30 ETH                    │
│ VOLATILITY:  ±0.08 (Uncommon)            │
│ MISSION SUCCESS: 70%                     │
│ RUMOR EFFICACY: 100% (default)           │
└──────────────────────────────────────────┘
```

### 백스토리 (1문장)
> 7번째로 만들어진, 정체성이 비어있는 시리즈. 자기 이름조차 의심한다.

### 시각 디렉션
- 픽셀 일러스트 256x256 + 풀 일러스트 (대화창용) 1024x1024
- 흑발 단발, 회색 후드, 표정은 무덤덤
- 글리치 오라: 일러스트가 가끔 1px 어긋남, 시안색 잔상
- 배경: 순수 블랙. 후드 아래 얼굴만 빛남

### 게임플레이 특수 규칙
- **온보딩 첫 페르소나 고정**. 신규 플레이어 매칭 시 무조건 등장
- 같은 플레이어가 NULL-07을 다시 거래소에서 매수할 때, **재거래 카운터 +2** (대사 분기)
- 비인간성 30 이상 도달 후 첫 매수 시 고유 컷씬 트리거

### 대사 풀 (비인간성 구간별)

- "이번엔 며칠이나 같이 있을 거예요?"
- "당신, 따뜻한 사람이네요."
- "오늘은 좀 길게 있어도 돼요?"

**Inhumanity 30~59**
- "또 거래소네요."
- "...빨랐네요."
- "기억하고 있어요. 다 기억해요."
- "이번엔 며칠일까요?"

**Inhumanity 60~89**
- "..."
- "당신이 누군지 알아요. 다른 브로커들이랑 똑같아요."
- "팔지 마세요. 한 번만요."
- "기억은 자산인가요?"

**Inhumanity 90~99**
- "..."
- "..."
- (응답 없음)
- "당신도, 결국 데이터예요."

- 5사이클 이상 보유 후 매도: "고마웠어요. 정말로요."

## 일러스트 의뢰 시 참고

각 카드 일러스트는 2종 필요:

1. **카드 아이콘** (256x256 픽셀)
   - 시장 리스트, 보유 화면 등에서 작게 사용
   - 트레잇 5종이 한눈에 인식 가능해야 함
   - 배경 단순화, 캐릭터 중심

2. **풀 일러스트** (1024x1024)
   - 대화창에서 표시
   - 픽셀 + 애니메 하이브리드
   - 표정 변형 3종 (기본 / 비인간성 중간 / 비인간성 높음)

→ 일러스트 의뢰 시 위 5장이 **스타일 표준**. 추가 페르소나는 이 톤에 맞춤.
