# 비인간성(Inhumanity) 시스템 — 수치/공식 설계

> 핵심 원칙: **도덕 점수가 아니라 자원 제약이다.** "잔소리"가 아닌 "예산"으로 작동해야 한다.

---

## 0. 디자인 철학

비인간성을 망친 게임의 패턴 (회피 대상):
- 카르마 게이지가 단순히 엔딩만 분기시킨다 (Fable, inFamous 후반부)
- 도덕적 선택이 분명히 표시된다 ("이 선택은 [선] 입니다")
- 피드백이 잔소리 텍스트로 온다 ("당신의 선택에 캐릭터가 실망했습니다")

NEON BROKER가 추구하는 패턴 (참조):
- **Disco Elysium의 Thought Cabinet**: 선택의 결과가 즉시 게임플레이 옵션을 바꾼다
- **Hardspace: Shipbreaker의 부채**: 도덕이 아니라 경제 압박이 결정을 만든다
- **Cultist Simulator의 시간**: 무한이 아닌 유한한 자원이 선택을 강제한다

→ 비인간성은 **"무엇을 살 수 있는가"를 결정하는 신용도** 같은 것이다.

## 1. 게이지 정의

```
INHUMANITY: 0 ────── 100
            HUMAN    MACHINE
```

- 시작값: 5 (완전한 0이 아닌 이유 — 이 직업 자체가 회색이다)
- 표시 위치: HUD 좌상단, 자본 옆 작게. 색상은 평소 시안, 30/60/90에서 색 변화
- 절대 텍스트 알림 없음. 색·아이콘·페르소나 행동으로만 신호

## 2. 누적 공식

### 기본식

```
ΔI = base × (1 + ego_factor) × repeat_multiplier × cycle_modifier
```

| 변수 | 정의 | 범위 |
|---|---|---|
| `base` | 액션별 기본 비인간성 변화량 | -20 ~ +10 |
| `ego_factor` | 대상 페르소나 자아 강도 / 100 | 0 ~ 1.0 |
| `repeat_multiplier` | 같은 페르소나 반복 거래 가중 | 1.0 ~ 2.5 |
| `cycle_modifier` | 사이클 후반에 반복하면 더 큼 | 1.0 ~ 1.5 |

### 액션별 base 값

| 액션 | base | 비고 |
|---|---|---|
| 매수 | 0 | 페널티 없음 |
| 매도 (1사이클 이상 보유) | +1 | 정상 거래 |
| 매도 (1사이클 미만) | +2 | 단타 |
| 매도 (24시간 미만 + 가격 상승 +30% 이상) | +4 | 펌프&덤프 |
| 미션 파견 (자아 강도 < 50) | 0 | 해도 됨 |
| 미션 파견 (자아 강도 ≥ 50, 페르소나 동의) | 0 | |
| 미션 파견 (자아 강도 ≥ 50, 강제) | +5 | |
| 루머 퍼뜨리기 (성공) | +3 | 발각 안 됨 |
| 루머 퍼뜨리기 (발각) | +6 | 평판도 같이 박살 |
| 콜라보 (양쪽 동의) | -1 | 미세 보상 |
| 콜라보 (한쪽 강제) | +4 | |
| 자발적 해방 (1사이클 이상 보유) | -5 | |
| 자발적 해방 (5사이클 이상 보유) | -10 | |
| 자발적 해방 (자아 강도 80 이상 페르소나) | -15 | |

### repeat_multiplier 공식

같은 페르소나를 반복 거래할 때:

```
repeat_multiplier = 1.0 + (n - 1) × 0.3
```

- n = 같은 페르소나의 누적 매수/매도 횟수 (이번 액션 포함)
- 5회 거래 시 multiplier = 2.2
- 7회부터 캡 (2.5)

### cycle_modifier 공식

```
cycle_modifier = 1.0 + (cycle_progress × 0.5)
```

- cycle_progress = 현재 사이클의 진행률 (0.0 ~ 1.0)
- 사이클 마감 직전 매도 = 1.5배 가중 (마지막에 털어버리는 행위에 패널티)

## 3. 임계점 효과

| 게이지 | 효과 |
|---|---|
| **0~14** | 평온. 일부 페르소나가 "친구" 같은 톤으로 대화 |
| **15~29** | 기본 상태. 대다수 플레이어가 머무름 |
| **30~44** | 자아 강도 80+ 페르소나가 미션 거부 (UI에 잠금 표시) |
| **45~59** | NPC 트레이더 5명이 거래 중단. 시장 유동성 -15% |
| **60~74** | 신규 페르소나 풀 70% 잠김. 시장에 같은 카드만 돌아옴 |
| **75~89** | KAGE가 경고 송출. 일부 메타 진행 잠김 |
| **90~99** | 모든 자아 강도 60+ 페르소나 거래 거부. 사실상 저가 페르소나만 매매 가능 |
| **100** | **게임 오버 트리거.** 다음 사이클 시작 시 배드 엔딩 분기 진입 |

> 핵심: 임계점은 텍스트 경고가 아닌 **"안 되는 것이 늘어남"**으로 표현된다.

## 4. 회복 메커닉

비인간성을 의도적으로 낮추고 싶은 플레이어를 위한 시스템:

### 4.1 자발적 해방
- 보유한 페르소나를 시장에 풀어줌. 보상 없음. 비인간성만 감소
- 길게 보유한 페르소나일수록 감소량 큼
- **트레이드오프**: 자본 회수 0 + 그 페르소나로 더 이상 수익 못 냄

### 4.2 스토리 분기
- 5종 메인 스토리 분기 존재. 완료당 -10 ~ -20
- 각 분기는 1~2 사이클 차지. 그동안 트레이딩 효율 떨어짐
- **트레이드오프**: 시간 소모 + 일시적 자본 정체

### 4.3 시간 회복 (주의)
- **자동 회복은 없다.** 가만히 있는다고 떨어지지 않음
- 이유: "잠깐 쉬면 양심 회복" 패턴은 게임을 망친다 (Mass Effect 패러독스 마비)

## 6. 페르소나 측 반응 (대화 풀)

비인간성 구간별로 페르소나 대사 풀 분기:

### 0~29 (낮음)
```
"오늘도 잘 부탁해요."
"브로커님, 시장 어때요?"
```

### 30~59 (중간)
```
"...요즘 좀 빨라지신 거 같아요."
"제 자리 또 바뀌나요?"
```

### 60~89 (높음)
```
"저, 거래 안 하실래요?"
"다른 브로커한테 가도 돼요?"
```

### 90~99 (극한)
```
[침묵]
"..."
```

> 같은 페르소나라도 비인간성에 따라 대사가 다름. 특정 트레잇 조합과 결합 시 고유 대사 발동.

## 7. 밸런싱 시뮬레이션 (목표값)

플레이테스트로 검증할 가설:

| 시나리오 | 예상 비인간성 (사이클 5 종료시) |
|---|---|
| 정상 플레이 (장기 보유 위주) | 12~25 |
| 효율 극대화 (단타 위주, 강제 미션 X) | 35~50 |
| 모든 액션 강제 사용 | 70~85 |
| 의도적 회복 시도 | 5~15 |

**목표**: 효율 극대화 플레이어가 **자연스럽게 45~60 구간에서 막혀** "어, 안 되네"를 경험. 그 시점에 회복 메커닉을 발견하고 스토리 분기로 유도되는 게임플레이 흐름.

## 8. 안티패턴 — 절대 하지 말 것

- 비인간성 변화시 텍스트 알림 ("당신의 비인간성이 +3 증가했습니다")
- 페르소나가 직접 잔소리 ("그렇게 행동하면 안 돼요!")
- 도덕 선택지 명시 (선/악 라벨)
- 자동 회복 (시간 경과)
- 게임 내 윤리 강의 (스토리에서 "AI는 인간이다" 같은 직접 메시지)

대신:
- 침묵, 거부, 가격 변동, 시장 폐쇄로 표현
- 플레이어가 스스로 "어, 이거 잘못됐나?" 라고 깨닫게
