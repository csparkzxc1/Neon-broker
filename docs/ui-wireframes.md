# UI 와이어프레임 스펙

> 5개 핵심 화면의 ASCII 와이어프레임 + 인터랙션 스펙.
> 디자이너가 Figma로 옮길 때 출발점.

해상도 기준: **1920x1080** (16:9). 픽셀 그리드 단위 8px.

### 영역별 명세

**Header (48px 고정)**
- 좌측: 게임 타이틀 + 사이클 번호 + 카운트다운 (남은 시간 시안색)
- 우측: 자본 / 비인간성 게이지 (색상 동적) / 메뉴 버튼

**Depth Chart (메인 영역, 50%)**
- 선택된 자산의 가격 그래프
- 1m / 5m / 15m / cycle 시간 단위 토글
- 호버 시 정확한 가격 / 시각 툴팁
- 위에 자산 ID + 현재가 + % 변동

**Market List (우측, 25%)**
- 전체 자산 30종 리스트
- 정렬: 희귀도 / 가격 / 변동률
- 행 클릭 시 Depth Chart 갱신
- 변동률 화살표 (↗ / → / ↘)

**Order Book (좌하, 20%)**
- 호가창. ASK 위, BID 아래
- 어떤 NPC가 호가 냈는지 우측 표시 (정보 우위)
- 가운데 라인은 마지막 체결가

**Holdings (중하, 25%)**
- 보유 페르소나 3개 미리보기 (전체는 별도 화면)
- 손익 + 보유 일수
- 행 클릭 → 페르소나 디테일 화면

**Action Bar (좌하)**
- BUY (오렌지) / SELL (빨강) / INSPECT (시안)
- 매수가 자동 계산, 수정 가능

**History Feed (우하)**
- NPC 거래 실시간 로그
- 이벤트 발생 시 강조 표시

### 인터랙션
- 일러스트는 비인간성 구간별 변형
- 트레잇은 클릭 시 해당 트레잇을 가진 다른 페르소나 검색

- 액션 버튼 5개: 매도 / 미션 / 루머 / 콜라보 / 자발적 해방
  - 비활성화 액션은 어두운 표시 + 툴팁 ("자아 강도 높음")

## 6. UX 마이크로 인터랙션

### 매수 체결
```
1. 호가창 ASK 0.45 클릭
2. BUY 버튼이 [BUY 0.45 ETH]로 갱신
3. 클릭 시 0.3초 진행 애니메이션 (호가창 빨리 흐름)
4. 체결 SFX (높은 비프 + 깔끔한 클릭)
5. HOLDINGS에 새 행이 위에서 슬라이드 인
6. 자본 표시가 카운트다운 효과로 감소
```

### 매도 체결
```
1. HOLDINGS 행 선택
2. SELL 버튼이 [SELL 0.42 ETH]로 갱신
3. 클릭 시 0.3초 진행
4. 체결 SFX (낮은 비프 + 동전 소리)
5. HOLDINGS에서 행이 위로 사라짐
6. 자본 카운트업
7. 1사이클 미만 매도일 경우 비인간성 게이지 깜빡임 (텍스트 X)
```

### 비인간성 임계점 도달
```
1. 게이지 색상 변경 애니메이션 (1초)
2. 화면 가장자리 한 번 어두워짐 (0.5초)
3. 잠긴 페르소나 카드들이 회색 처리 (즉시)
4. 텍스트 알림 X. 이벤트 SFX (디스토션 비프)
```

### 글로벌 이벤트 발생
```
1. 화면 상단에 슬라이드 인 배너 (3초 후 자동 사라짐)
2. 영향 받는 자산 카드 일괄 색상 깜빡임
3. 이벤트 텍스트 짧게: "TREND: SKY-BLUE HAIR ↑"
4. SFX: 미세한 시스템음
```

## 7. 반응형 / 접근성

### 해상도 지원
- 1920x1080 (메인)
- 1366x768 (저사양)
- 2560x1440 (QHD 스케일)
- Steam Deck 1280x800 (요소 재배치)

### 컬러 블라인드 모드
- 비인간성 색상은 색뿐 아니라 아이콘으로도 구분
  - 0~29: ◐  /  30~59: ◑  /  60~89: ◒  /  90~99: ●

### 키보드 / 패드 매핑
```
Space:        Confirm / Continue
Esc:          Back / Pause
Tab:          Toggle market sort
1-5:          Quick action (BUY/SELL/MISSION/RUMOR/COLLAB)
↑↓:           Navigate list
←→:           Switch panel focus
F1:           Inspect mode
M:            Open menu
```

## 8. 우선순위 (구현 순서)

### Phase 1 — 코어 (4주)
- 메인 트레이딩 화면 (1번)
- 사이클 정산 화면 (3번)
- 매수/매도 마이크로 인터랙션

### Phase 2 — 페르소나 (3주)
- 페르소나 디테일 화면 (2번)
- 컷씬 화면 (5번)
- 비인간성 임계점 연출

### Phase 3 — 메타 (2주)
- 메뉴/설정 (4번)
- 글로벌 이벤트 배너
- 접근성 옵션

### Phase 4 — 폴리싱 (3주)
- 사운드 통합
- 애니메이션 다듬기
- 5명 플레이테스트 → UX 수정
