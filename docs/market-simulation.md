# 시장 시뮬레이션 — NPC 트레이더 10명 + 동역학

> MVP 범위: NPC 10명. 정식 빌드는 50명.
> 목표: 매 사이클마다 다른 시장이 만들어지는 느낌. 메타 학습 가능한 깊이.

---

## 0. 시장 모델 개요

NEON BROKER의 시장은 **"50명의 NPC 트레이더가 각자 다른 알고리즘으로 거래하는 한정된 풀"**이다.

### 핵심 원리
- 가격 = 마지막 체결가. 호가창 + 깊이 차트로 시각화
- 매 틱(현실 30초)마다 NPC가 자기 패턴에 따라 매수/매도 호가 갱신
- 플레이어는 "51번째 트레이더"로서 동일한 시장에 참여
- 각 NPC는 자체 자본/포트폴리오/선호를 가짐

### 가격 결정 공식 (단순화)

```
new_price = last_price × (1 + supply_demand_pressure × volatility)
            + trend_drift
            + event_shock
```

| 변수 | 설명 |
|---|---|
| `supply_demand_pressure` | 호가창 매수/매도 비율 기반 (-1 ~ +1) |
| `volatility` | 페르소나 희귀도별 (커먼 0.05, 레전더리 0.25) |
| `trend_drift` | 글로벌 메타 트렌드 영향 (예: "쿨한 헤어가 유행") |
| `event_shock` | 이벤트 발생 시 일회성 충격 (-30% ~ +50%) |

## 1. NPC 트레이더 아키타입 10명

### 패턴 분류

각 NPC는 4가지 축에서 위치를 가짐:
- **공격성** (소심 ↔ 공격적)
- **시간 지평** (단타 ↔ 장기보유)
- **정보 의존** (감 ↔ 데이터)
- **트렌드 추종** (역추세 ↔ 모멘텀)

## 3. 글로벌 이벤트

매 사이클마다 0~2개 이벤트 발생. 시장에 충격을 줌.

### 트렌드 변화 (40% 확률)
- 특정 트레잇이 유행. 해당 트레잇 보유 페르소나 +15~30%
- 예: "하늘색 머리가 핫함", "기계 의수 유행"
- ORACLE-3가 1턴 전에 진입하므로 추론 가능

### 정부 단속 (15% 확률)
- 자아 강도 80+ 페르소나 거래 일시 중지 (1~2턴)
- 시장 유동성 -25%
- 회복 후 가격 +10% (희소성 증가)

### 경쟁 브로커 출현 (20% 확률)
- 신규 NPC 트레이더가 사이클 종료까지 활동
- 플레이어와 직접 경합 (같은 페르소나 노림)

### 페르소나 파업 (10% 확률, 비인간성 50+에서만)
- 자아 강도 70+ 페르소나 일부가 거래 거부
- 비인간성 회복 액션으로만 해제

### 시장 호황 (15% 확률)
- 모든 페르소나 가격 +5~10% (거래량 +30%)
- 단타 보너스. 그러나 비인간성 가중치도 +20%

## 4. MVP 솔로 빌드 검증 항목

캐릭터 시스템 없이 시장만 빌드해서 검증:

- [ ] 매 사이클마다 시장이 다르게 느껴지는가? (NPC 패턴이 충분히 다양한가)
- [ ] 5 사이클 후 메타 학습이 가능한가? ("ORACLE-3 따라가면 돈 번다" 같은 발견)
- [ ] 호가창 / 깊이 차트가 직관적인가?
- [ ] 플레이어가 시장에서 자신만의 전략을 만들 수 있는가?
- [ ] 30분 세션이 짧지도 길지도 않은가?

만약 캐릭터 없이 **트레이딩 자체로 안 재밌으면**, 페르소나 추가해도 안 재밌다. 솔로 빌드 검증이 첫 게이트.

## 5. 정식 빌드 확장 (50 NPC)

10명의 아키타입을 5종 변형으로 늘려 50명 구성:
- 자본 규모, 선호 트레잇, 등장 빈도 등을 변주
- 각 사이클마다 활성화되는 NPC 35~40명 (전부 매번 등장 X)
- 일부는 특정 사이클/이벤트에서만 등장 (희귀 트레이더)

NPC 다양성이 시장 깊이를 만든다. 단순 알고리즘 X, 고유 캐릭터로 인식되도록.
