# 온보딩 시나리오 — 첫 10분

> 목표: 트레이딩 UI의 진입장벽을 부수고, **2분 내에 첫 거래 / 5분 내에 첫 페르소나 애착 / 10분 내에 비인간성 게이지 자각**을 만든다.

핵심 원칙:
- 튜토리얼 텍스트로 설명하지 않는다. 손으로 누르게 한다.
- 첫 번째 페르소나는 강제로 좋아하게 만든다. 그 다음 그 페르소나로 도덕적 갈등을 유도한다.
- 시장 메커닉은 "사면 오르고, 팔면 끝난다" 하나만 먼저 가르친다.

---

## 분 단위 비트 시트

### 0:00 — 콜드 오프닝 (15초)

검은 화면. 픽셀 비프음.

```
> CONNECTION ESTABLISHED
> NEO-TOKYO UNDERMARKET v0.4.7
> WELCOME, BROKER.
```

타이핑 효과로 한 줄씩 등장. 스킵 불가. 분위기 셋업.

### 0:15 — 멘토 NPC 등장: KAGE (1분)

검은 화면에 시안색 풀일러스트. 채팅창 스타일 대화.

```
KAGE: 너 신참이지.
KAGE: 월세 밀린 거 알아. 한 명만 굴리면 풀려.
KAGE: 내가 지갑에 1.5 ETH 꽂아놨다. 지금 시장에 들어가.
```

플레이어는 "OK" 하나만 누른다. 선택지 없음. **에이전시는 나중에.**

### 1:15 — 첫 시장 화면 (45초)

깊이 차트가 화면 60%를 차지. 우측에 페르소나 5장 카드 그리드. 가격만 표시 (0.3 ~ 1.2 ETH).

```
[하이라이트 화살표] → 가장 저평가된 카드 (NULL-07, 0.3 ETH)
[툴팁] "이건 트레잇이 좋은데 가격이 낮다. 매수해."
```

매수 버튼 외에 모든 UI 비활성. 클릭 한 번에 거래 체결. 만족스러운 SFX. 보유 화면으로 자동 전환.

### 2:00 — 첫 페르소나 만남: NULL-07 (90초)

화면 중앙에 NULL-07 풀일러스트. 글리치 효과. 자동 대사:

```
NULL-07: ...누구세요?
NULL-07: 아, 저 또 팔렸군요.
NULL-07: 이번엔 며칠이나 같이 있을 거예요?
```

선택지 3개 제공:
1. "오래 같이 있을 거다."
2. "필요할 때까지만."
3. (대답 안 함)

> 어떤 답을 골라도 시스템은 기록만 한다. NULL-07은 살짝 미소짓고 사라진다. **이 대화가 1분 후 시장 가격에 반영된다.**

### 3:30 — 시장 변동 + 첫 매도 유혹 (90초)

알림: "NULL-07 가격 +0.4 ETH (시장 트렌드)."

```
KAGE: 봤지? 70% 차익이다. 팔아.
[매도 버튼] [보류 버튼]
```

여기서 갈림길:

- **매도 선택**: 시원한 SFX, +0.4 ETH 정산. 직후 NULL-07이 한 줄 보낸다: `"...어. 빨랐네요."` 비인간성 게이지 +1 (작게 노란불 점멸). **여기서 게이지를 처음 보여준다.**
- **보류 선택**: KAGE가 "신참은 다 그래. 다음엔 팔아." 라며 넘어간다. 가격은 다시 떨어진다. **체험으로 기회비용을 가르친다.**

> 어느 쪽을 골라도 다음 단계로 진행된다. 잘못된 선택은 없음. 둘 다 게임의 진짜 모습.

### 5:00 — 자유 매수 (2분)

UI 잠금 해제. 시장에는 페르소나 카드 12장. 플레이어는 자기 자본으로 자유롭게 매수.

```
KAGE: 이제 알아서 해. 다음 사이클까지 30분.
```

보조 안내는 화면 우하단 작은 툴팁만. 시장 사이클 타이머가 처음 등장.

### 7:00 — 첫 미션 파견 액션 해금 (1분)

보유한 페르소나 중 하나에 새 버튼 등장: "MISSION."

미션 파견 → 5분 후 평판 +10 + 가격 +0.1 ETH. 단, **자아 강도 70 이상이면** 페르소나가 거부 대사 송출:

```
KAYA-22: 또요? 저번에 이미 했잖아요.
[강제 파견] [취소]
```

강제 파견하면 비인간성 +5. 여기서 처음으로 **"비인간성은 단순 도덕이 아니라 자원 제약"**을 깨닫게 된다. 강제 파견 시 KAGE가 한 줄:

```
KAGE: 너무 굴리면 시장에서 밀려나. 적당히 해.
```

### 8:00 — 비인간성 임계 자연 발생 (선택적)

만약 플레이어가 빠른 매도를 반복했다면 비인간성 15~25 도달. NULL-07이 다시 등장:

```
NULL-07: 저, 다시 거래소에 올라왔어요.
NULL-07: 이번엔 그냥 인사하려고요.
```

매수 가능. 단가는 첫 매수가의 1.3배. **"같은 페르소나 반복 거래"로 비인간성 +2.** 메시지 없이 게이지만 슬쩍 오른다.

### 9:00 — 첫 사이클 종료 카운트다운 (1분)

타이머 60초. 화면 전체가 카운트다운 모드로 전환:

```
> CYCLE ENDS IN 00:60
> CURRENT CAPITAL: 2.34 ETH
> TARGET: 2.00 ETH ✓
```

플레이어가 매도 안 한 페르소나는 다음 사이클로 이월. **"내가 끝까지 안 판 애들"**이라는 작은 결속감을 만든다.

### 10:00 — 정산 화면 + 훅

```
> CYCLE 1 COMPLETE
> NET PROFIT: +0.84 ETH
> INHUMANITY: 8 / 100
> RETAINED PERSONAS: 3

KAGE: 잘했어. 그런데 NULL-07은 왜 안 팔았어?
KAGE: ...뭐, 다음 사이클에서 보자.

[CYCLE 2 시작] [저장하고 종료]
```

훅 트리거: "다음 사이클로 가면 NULL-07이 또 뭐라고 할까?" — 세션을 한 번 더 누르게 만드는 미끼.

## 온보딩이 가르치는 것 (체크리스트)

- [x] 매수/매도 메커닉 (2분 내)
- [x] 깊이 차트 읽는 법 (자연스럽게 노출)
- [x] 페르소나가 말한다는 사실 (2분)
- [x] 가격은 변동한다 (3:30)
- [x] 비인간성 게이지의 존재 (3:30)
- [x] 미션 파견 액션 (7분)
- [x] 비인간성은 자원 제약이다 (7분)
- [x] 같은 페르소나 재거래 메커닉 (8분)
- [x] 사이클 시스템 (9분)
- [x] 다음 세션 훅 (10분)

루머/콜라보 액션은 사이클 2에서 해금. 이 단계에서는 일부러 가르치지 않는다.

## 안 가르치는 것 (의도적)

- 메타 진행 시스템
- 평판/브로커 평판
- 자아 강도 수치
- 트레잇 풀 전체

> 첫 10분에 모두 가르치면 이탈한다. **궁금증을 남긴다.**

## 개발 노트

- KAGE의 톤은 무뚝뚝하고 짧게. 라이트 노벨 멘토 X. 야쿠자 중간 보스 ○
- NULL-07은 첫 페르소나로 고정. 이름의 의미("0번째, 빈 상태")가 후반 스토리 분기에서 회수됨
- 모든 텍스트는 트위터 길이 이하
- SFX 우선순위: 매수 체결 > 매도 체결 > 가격 변동 > 게이지 증가
