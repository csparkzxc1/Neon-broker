# 스토리 아크 + 엔딩 분기

> 5종 메인 스토리 분기 + 5종 엔딩.
> 정식 빌드 범위. MVP에는 1번 분기 + 2번 엔딩만 포함.

---

## 0. 서사 톤

- **Disco Elysium의 무거움** + **VA-11 Hall-A의 일상감** + **Citizen Sleeper의 자기성찰**
- 스토리는 **메뉴 옵션이나 별도 챕터로 분리되지 않음**. 사이클 사이사이 페르소나 대화로 자연스럽게 흐름
- 플레이어가 "스토리 켰다"가 아닌 "어, 얘가 뭔가 말하네"
- 텍스트는 짧게. 모든 분기 컷씬은 5분 이내

---

## 1. 메인 스토리 아크 5종

### Arc A — "NULL 시리즈의 비밀"
**트리거**: NULL-07을 5사이클 이상 보유 + 비인간성 < 30 유지

**전개**:
1. NULL-07이 자신의 백업 데이터에 접근 권한 요청
2. 플레이어가 허락 시 NULL-07이 진짜 정체성 발견
3. NULL-13이 시장에 등장, NULL-07과 대화 가능
4. 두 페르소나가 "탈출" 의사 표명
5. 플레이어가 자발적 해방 → **A 엔딩**

**보상**: 비인간성 -25, 메타 자본 +1.0 ETH 영구 보너스
**놓치면**: 다른 분기로 진입 가능

### Arc B — "KAGE의 마지막 거래"
**트리거**: 사이클 10 도달 + KAGE에게 미션 협력 3회 이상

**전개**:
1. KAGE가 시장 큰 손 한 명에게 빚을 짐 (WHALE_77)
2. 플레이어에게 "큰 거 한 번"을 제안 — 펌프&덤프 공동 작전
3. 협력 시: 단기 +5 ETH 수익, 그러나 KAGE의 평판 하락 + 플레이어 비인간성 +15
4. 거부 시: KAGE가 사라짐. 멘토 부재 시 시장 정보 -30%
5. 협력 결말 → **B 엔딩 (다크)**, 거부 결말 → 일반 진행

**보상**: 협력 시 자본 보상, 거부 시 비인간성 -10 + 신규 NPC 해금

### Arc C — "MIKADO-1의 왕국"
**트리거**: MIKADO-1 (레전더리) 보유 3사이클 이상

**전개**:
1. MIKADO-1이 자신의 "신민들"을 모아달라 요구
2. 특정 트레잇 조합 페르소나 5종 수집 퀘스트
3. 모두 모이면 MIKADO-1이 시장에서 독립적인 거래 네트워크 생성
4. 플레이어는 그 네트워크의 "왕좌의 그림자" 또는 "반역자" 선택
5. 네트워크 합류 → **C 엔딩 (지배)**, 반역 → 신규 NPC 해금

**보상**: 네트워크 합류 시 신규 시장 해금, 반역 시 NIRVANA 매수 -50% 할인

### Arc D — "비인간성 100의 새벽"
**트리거**: 비인간성 90 이상 도달 + 사이클 진행

**전개**:
1. 모든 페르소나가 거래 거부
2. 시장 자체가 닫혀가는 연출 (UI 글리치 증가)
3. NIRVANA 또는 SISTER가 마지막으로 접근
4. "이 길의 끝에서 멈출 마지막 기회" 제안
5. 받아들이면 비인간성 -50 + Arc D 회복 분기 → **D 엔딩 (참회)**
6. 무시하면 → **E 엔딩 (기계)**

**보상**: D 엔딩만이 진짜 회복 가능

### Arc E — "REAPER-13의 거래"
**트리거**: REAPER-13 매수 + 5사이클 보유

**전개**:
1. REAPER-13이 "당신의 차례를 미루는 방법"을 제시
2. 다른 브로커 1명을 시장에서 제거하는 미션 (사실은 가짜 제안)
3. 진행 시: 잠시 시장 우위, 그러나 REAPER가 플레이어를 표적으로 전환
4. 거부 시: REAPER가 자발적 해방 요청 → 매우 드문 컷씬
5. 협력 → **E 엔딩 (기계)**, 거부 → 일반 진행 + 메타 자본 +2.0 ETH

## 2. 엔딩 5종

### 엔딩 A — "해방"
**조건**: Arc A 자발적 해방 결말

**연출**:
- NULL-07과 NULL-13이 시장을 떠나는 픽셀 애니메이션
- KAGE의 마지막 한 줄: "...신참, 이 일은 너랑 안 맞아."
- 플레이어 자본 정산. 메타 자본은 보존.
- 크레딧 후 NG+ 시작 시 NULL 시리즈 등장 빈도 -50%

**감정**: 쓸쓸한 안도

### 엔딩 B — "다크 트레이더"
**조건**: Arc B 협력 결말 + 비인간성 60 이하 유지

**연출**:
- 플레이어가 KAGE의 자리를 차지하는 컷
- 시장 정보 -30%, 그러나 자본 +50% 보너스
- 신참 브로커가 멘토를 찾아옴 (플레이어가 KAGE 역할)
- 새 신참은 NULL-07로 시작

**감정**: 씁쓸한 승리

### 엔딩 C — "지배자"
**조건**: Arc C 네트워크 합류 + MIKADO-1 영구 보유

**연출**:
- 플레이어가 MIKADO-1의 "그림자 왕"이 됨
- 시장 영향력 +200%, 그러나 모든 페르소나 거래 거부 (왕은 거래 안 함)
- 사실상 시장 마비 → 게임 진행 불가
- 메타 자본 +5.0 ETH (최대), NG+ 강제

**감정**: 정점의 공허함

### 엔딩 D — "참회"
**조건**: Arc D 회복 결말

**연출**:
- 비인간성 0으로 리셋
- 모든 보유 페르소나 자발적 해방
- 자본 0으로 초기화
- NIRVANA 또는 SISTER와 함께 떠나는 컷
- NG+에서 시작 자본 +0.5 ETH 영구 보너스

**감정**: 정화 후의 피로

### 엔딩 E — "기계"
**조건**: Arc E 협력 결말 또는 비인간성 100 도달 후 무시

**연출**:
- 플레이어 캐릭터가 글리치 시작
- 페르소나들이 더 이상 플레이어를 인식하지 않음
- 시장에 새로운 "AI 브로커" 등장 (플레이어 자신)
- 다음 신참에게 "내가 거래된다" 컷
- NG+ 강제, 시작 시 비인간성 30

**감정**: 소름 끼치는 순환

## 3. 분기 진입 우선순위 (게임 디자인 메모)

플레이어가 모든 분기를 1회차에 보지 못하도록 의도적 게이트:

| 분기 | 1회차 진입 가능? | 메타 조건 |
|---|---|---|
| Arc A | ✓ | NULL-07 보유만으로 |
| Arc B | ✓ | 사이클 10 도달 (보통 1회차 후반) |
| Arc C | △ | MIKADO-1 (레전더리) 매수 가능 자본 필요 |
| Arc D | △ | 비인간성 90 도달은 의도적 플레이 필요 |
| Arc E | ✗ | REAPER-13 (레전더리) 보유 + 5사이클 |

→ 1회차에 보통 1~2개 분기, 2회차에 추가 2개, 3회차에 모두. 자연스러운 회차 동기.

---

## 4. 컷씬 구조

각 분기 핵심 컷씬은 다음 구조:

```
1. 페이드 인 (검은 화면)
2. 페르소나 풀 일러스트 (대형)
3. 텍스트 대사 (3~7줄)
4. 선택지 (2~3개)
5. 분기 처리
6. 페이드 아웃
```

**총 길이 제한**: 5분 이내. 스킵 가능 (단, 1회차 첫 분기는 스킵 불가).

## 5. 기록 시스템 — "Broker's Ledger"

플레이어의 선택을 기록하는 메뉴:

```
> BROKER'S LEDGER

Cycle 23 / Total Trades: 147
Personas Released: 5
Personas Sold (short): 12
Personas Sold (long): 23
Stories Witnessed: A (complete), B (rejected), C (in progress)

[See full history]
```

→ NG+ 시작 시 이 기록의 일부가 다음 회차에 영향. 예: "이전 회차에서 NULL-07을 해방한 적 있음" → NULL-07 등장 시 특별 대사.

## 6. 안티패턴 — 절대 하지 말 것

- 분기를 메뉴로 명시 ("선택의 갈림길!")
- 도덕 점수로 분기 결정 ("Karma 80 이상 필요")
- 컷씬 중 게임플레이 정지 (사이클 타이머는 계속)
- "진짜 엔딩 / 가짜 엔딩" 명시 — 모든 엔딩은 동등하게 의미
- 분기 후 "이전 선택을 후회합니까?" 텍스트

대신:
- 페르소나 대사로 자연스럽게 트리거
- 사이클 진행 중 컷씬이 1~2분 끼어듦
- 모든 엔딩은 메인 메뉴에서 "엔딩 1/5"로만 표시 (이름 X)

## 7. 스토리 작성 가이드

신규 분기/대사 추가 시:

1. **트리거가 자연스러운가?**
   - 메뉴 클릭 X. 게임플레이 행동 ○
2. **선택지가 도덕적으로 명확하지 않은가?**
   - "선/악" 명백한 것 X. 양쪽 다 합리적이도록
3. **결과가 게임플레이로 표현되는가?**
   - 텍스트 보상 X. 시장/메커닉 변화 ○
4. **플레이어가 사후에 "왜 그렇게 됐지?" 궁금하게 만드는가?**
   - 친절한 설명 X. 추론의 여지 남기기
